# H07 — Installable PWA and safe offline workflows (subsystem plan)

Four serial slices. Only slice 1 ships in Wave 10 (H07-A). Roadmap acceptance (flight-mode write once,
A→B login reveals nothing, token expiry pauses sync, conflicts need review, pending money looks
different) is split across slices 2–4.

## Rules for every slice

1. **Account isolation.** Anything stored on the device (cache, queue) is keyed by user ID. Logout,
   account replacement or `SessionService.reset()` purges it before the next login renders. Never
   serve account A's cached data to account B.
2. **Tokens stay in memory.** Nothing the service worker or IndexedDB holds contains an access or
   refresh credential. An expired access token pauses sync (state "sign in to sync") and never
   silently re-sends under another identity.
3. **Pending money looks different.** Queued or cached-unconfirmed amounts render with a distinct
   badge/style and never count in confirmed balances or totals.
4. **No real-money transfers queued.** Settlements/payments are online-only. Only expense create/edit
   writes may queue.
5. **Do not claim more than exists.** Each slice states exactly what works offline.

## Slice 1 — installability and app shell (H07-A, shipped)

- `@angular/service-worker` pinned exactly to the Angular version (21.2.17); `provideServiceWorker`
  enabled outside dev mode, `registerWhenStable:30000`; `serviceWorker: ngsw-config.json` in the
  production build only.
- `ngsw-config.json`: prefetched `app` group (index, JS, CSS, fonts, manifest, favicon), lazy
  `assets` group (`/i18n/*.json`, icons, images). **No `dataGroups`**: API responses are never cached.
  `navigationUrls` excludes `/api` and file-like URLs.
- `manifest.webmanifest` (start `/dashboard`, standalone, Seafoam theme/background colours), 192/512
  and maskable icons, `theme-color` meta, apple-touch-icon.
- `core/pwa/pwa-update.service.ts`: on `VERSION_READY` activate and reload at the **next router
  navigation**; on `unrecoverable` reload once per tab session. No UI.
- Offline now: reload shows the cached shell; data calls fail into the existing retry states.

### Rollback (kill switch)

Publish a Pages deploy whose `ngsw-worker.js` is `node_modules/@angular/service-worker/safety-worker.js`
(it unregisters itself and clears the `ngsw:` caches) and whose `ngsw.json` is absent. Installed
clients pick it up on their next worker update check (within ~24 h, or at next navigation-triggered
check). Then ship a normal build with `provideServiceWorker` removed. The worker is browser-side only:
no backend or schema step.

### Deployment note

Cloudflare Pages serves static files with `Cache-Control: public, max-age=0, must-revalidate` by
default and the repo has no `_headers` file, so `ngsw.json` and `ngsw-worker.js` are revalidated
each time. Angular also requests `ngsw.json` with a cache-busting query. No deployment file changed.

## Slice 2 — account-scoped read cache

IndexedDB read cache for dashboard, group detail, balances and history, keyed `userId`. Cached
reads render with a visible "saved <time>" stale marker; every read still revalidates when online.
Purged on logout/reset/replacement and on credential-version change. Needs: a `core/offline/` store,
a hook in `SessionService.reset()` (owned by A03 code: coordinate), tests for A→B isolation with a
real service worker/IndexedDB in a browser. Still no queued writes.

## Slice 3 — durable operation queue for expense writes

IndexedDB queue (per user) of expense create/edit/delete intents storing the E02 `operationId` and
the `expectedVersion` seen. Replays only after explicit reconnect with a valid token, one at a time,
using the existing keyed endpoints so a lost response is replay-safe. Same-intent dedupe; changed
membership or a 409 stops the item as "needs review" (slice 4). Integrates with `PendingWritesService`
(same account-owned identity rules). Payments excluded.

## Slice 4 — conflict and reconnect UI

Queue panel: pending (distinct styling), syncing, needs review, failed. Review shows the user's draft
beside current server state; actions are Keep mine (new version), Use server, Discard. Token expiry
shows "sign in to continue sync". Browser rehearsal: flight mode → draft → restart → reconnect writes
once; A logout → B login shows nothing of A.

## Test seam

Slice 1: `SwUpdate`-stubbed unit spec; production build artifacts; real Chrome (own user-data-dir)
against `ng build` output. Slices 2–4 additionally require the same real-browser seam plus HTTP
replay tests against the existing keyed endpoints.
