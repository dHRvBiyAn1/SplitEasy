My choice: Split Tip.

It belongs to SplitEasy’s split motif and stays precise around money. Keep the companion small and enable it only for a fine mouse pointer. On touch there is no cursor; on text fields keep the familiar text caret. Reduced motion keeps the static branded tip and removes the animated companion. Forced colors uses system cursors.

These are original, local previews. No cursor package, copied paid component or application change is included. Animation stops when the pointer leaves, the page hides or motion is reduced.
